FEATURED CASE STUDY / CCT270 / GAME DEVELOPMENT

Air Hockey — Designing an Interactive Game

A one-player air hockey game developed in Unity, combining gameplay design, player interaction and C# programming.

01 / PROJECT OVERVIEW

The idea

For my CCT270 game design project, I created a single-player air hockey experience. The goal was to turn a familiar arcade-style game into a digital experience with clear controls, visible scoring and a simple playfield.

02 / DESIGN CHALLENGE

Making gameplay easy to follow

I needed to design a layout where players could immediately recognize the rink, puck and paddle while keeping the game readable on a vertical screen. I used a simple visual system with a white rink, blue markings and contrasting game pieces.

03 / DEVELOPMENT PROCESS

Building the game in Unity

I worked in Unity and used C# scripts for game behavior. My development workspace includes separate scripts for player movement, the puck and scoring. I brought the visual design and gameplay logic together, then tested the experience in Unity's Game view.

Unity C# Game UI Interaction Design

04 / GAME FEATURES

Gameplay decisions

The project was planned around a two-minute match, multiple difficulty levels and a scoring system. The design also included a final 30-second double-points mechanic and additional obstacles for the highest difficulty setting.

These features describe the project design. The screenshot above shows the Unity development view rather than a complete gameplay demonstration.

05 / REFLECTION

What I learned

This project gave me a chance to connect visual design with programming. I practiced organizing game objects, writing scripts for interactions and considering how interface decisions affect the player's understanding of a game.
